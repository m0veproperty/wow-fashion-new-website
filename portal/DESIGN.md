# Wow Fashion workspace design

The portal extends the established Wow Fashion previews: warm cream, brown ink and blush. It is an operational workspace, with an editorial overview and compact, legible data views.

- **Body:** Inter, self-hosted; 12–14 px for dense working UI with sufficient line height.
- **Display:** Instrument Serif, self-hosted; reserved for primary page headings, the overview and a few empty states.
- **Surfaces:** paper `#faf8f5`, sidebar `#f1ebe4`, white forms, brown ink `#352821`, terracotta accent `#92533c`.
- **Structure:** Persistent left navigation, compact header, central workspace, full-width category inventory and contextual page/prompt detail views.
- **Interaction:** Hash routes, searchable/filterable records, explicit save actions, accessible native dialogs, keyboard focus indicators and reduced-motion support.
- **Responsive behaviour:** Navigation becomes a drawer below 720 px; cards and detail columns stack; wide data tables scroll inside their container.
- **State language:** Reference view, Shared workspace, Saving, conflict feedback, source-verified, proposed standard, needs evidence. Do not imply live data collection or approval from a score alone.
